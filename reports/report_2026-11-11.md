### OpenAI

**ChatGPT Desktop 将 SSH agent 转发到远程机器** ⭐—｜评分 9.7｜2026-11-09
ChatGPT Desktop 会把本地 SSH agent 转发至远程机器，使远程运行的 agent 可用本地凭据认证（例如向私有 GitHub 仓库推送），并附有 PR 作为佐证。
> **深入**：这是一条安全敏感度极高的产品行为。它极大提升了远程 agent 的实用性（无需在远端配置密钥），但同时把"本地凭据的信任边界"扩展到了远程执行环境——一旦远程机器被攻破或 agent 被诱导，本地私钥的可用范围即被放大。对使用 coding agent 的团队而言，这是必须纳入威胁建模的新默认行为。
> 🔗 https://news.ycombinator.com/item?id=50422628
