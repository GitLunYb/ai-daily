### Claude Duet ⭐— ｜评分 10.0 ｜2026-10-21
Anthropic 推出的主动型 agent 应用，会主动提示待办、代为执行任务，并在行动前向用户确认。([链接](https://claude.com/product/claude-duet))

**深入**：这是本周期信号最强的一条。Duet 的产品定位不是"更好的聊天框"，而是把 agent 从"被动响应"改成"主动推送"——它自己判断什么需要你注意。HN 评论区最有价值的一句是"这些 agent 助手很打动我内心的乐观主义者，但我很难迈出信任那一步"，这恰好点出该类产品的核心矛盾：**主动性越强，信任门槛越高**。530 条评论的讨论密度说明，这不是一次普通功能更新，而是关于"人机委托边界"的公开辩论。同日出现的 Ask HN 帖"如果模型这么好，OpenAI 为什么不自己开 100 家公司"（评分 10.0）与之形成互文：当模型能力足够强，产品形态的分歧就从"能不能做"转向"该由谁来做、责任归谁"。

### LLM 让形式化软件验证在大规模上变得可行 ⭐— ｜评分 9.8 ｜2026-10-22
Anthropic 研究：以 LLM agent 编写形式化证明，使软件验证的规模大幅扩展。([链接](https://www.anthropic.com/research/formal-verification))

**深入**：这是本周期技术含量最高的一条，也是评论区最尖锐的一条。HN 讨论中有人引用附录原文指出"agent 写出的证明与任何同一 theorem 的证明一样'好'，因为它们都证明了等价性定理"，随即有人反驳"要证明一个命题，该命题必须正确建模代码的现实"——**这正是形式化验证的经典软肋：证对了定理，不等于定理说对了事**。Anthropic 的真正贡献不在于"AI 会写证明"，而在于把证明生成的成本压到可以覆盖更大代码面的程度。若该路径成立，受益的将是编译器、密码库、航空航天等对正确性有硬要求的领域。但需清醒：验证链条的起点（规格是否正确）仍然由人负责，AI 只是把中间最昂贵的一段自动化了。
