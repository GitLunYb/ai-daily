## Model 模型

### Muse Glimmer：30B 常驻本地 Agent 模型 🆕⭐— Meta AI
**简介**：Meta 发布 Muse Glimmer，30B 参数，专为常驻本地 Agent 工作流优化，开源权重。
**评分**：10.0
**简评**：这是 Meta 开源战略的重要一步。社区讨论热烈，有评论者期待本周发布的 Qwen 3.8 27B 与之对比。30B 参数规模在本地部署与性能之间取得了较好平衡，对端侧 Agent 应用意义重大。

**深入分析**：Muse Glimmer 的核心价值在于"常驻本地"（always-on local）定位。与云端 API 调用不同，本地运行意味着低延迟、高隐私、离线可用，这对 Agent 的实时响应和敏感数据处理至关重要。30B 参数在消费级硬件上已可运行（配合量化），使得个人开发者和小团队也能部署自己的 Agent 模型。Meta 选择开源此模型，一方面是对社区期待"Meta 未放弃开源"的回应，另一方面也是与闭源阵营差异化竞争的策略。其与 Qwen 3.8 27B 的对比将成为近期社区关注的焦点。
🔗 [研究博客](https://research.meta.ai/blog/introducing-muse-glimmer-open-agentic-model)

### WeatherNext：气旋预报突破 ⭐— Google
**简介**：DeepMind 的 WeatherNext 模型在气旋预报上实现突破，可提前一天发出预警。
**评分**：9.9
**简评**：AI 在气象科学中的应用价值再次得到验证。多一天的预警时间意味着更多生命和财产可以得到保护。

**深入分析**：WeatherNext 的突破在于将 AI 模型应用于极端天气事件的精准预报。传统数值天气预报模型计算成本高、时效性有限，而 WeatherNext 通过深度学习从历史气象数据中学习模式，实现了更快的推理速度和更高的预报精度。"多一天的预警时间"看似微小，但对沿海地区和防灾部门而言意义重大。社区评论中有人提出"能否用 AI 预测地震"的期待，虽然地震预测的物理机制与气旋不同，但 WeatherNext 的成功无疑为 AI 在地球科学中的更广泛应用打开了想象空间。DeepMind 将 AI 从棋类游戏、蛋白质折叠拓展到气象预报，持续展示基础模型在科学发现中的潜力。
🔗 [DeepMind 博客](https://deepmind.google/blog/weathernext-ai-model-achieves-breakthrough-in-forecasting-cyclones/)
