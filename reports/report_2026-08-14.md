### DeepSeek Harness 开发者预览 — 评分 9.9 🆕
DeepSeek 推出的开源 Agent Harness（dsh），采用"一切皆插件"架构，基于 Cordis 构建，目前处于开发者预览阶段。

**深度解析**：DeepSeek Harness 的架构理念值得关注——将 Agent 的每个组件都抽象为插件，实现了极高的可组合性和可扩展性。与现有主流 harness（如 Claude Code、Codex CLI）的"单体应用"思路不同，dsh 的插件化设计允许开发者按需组装工具链。社区讨论中有人质疑其是否优于 omp（另一个 agent harness），也有人对 Node.js 生态的依赖表示疑虑。作为 DeepSeek 在 Agent 基础设施领域的首次布局，其生态潜力不容小觑。

[项目主页](https://deepseek.com/harness/en/) | [GitHub](https://github.com/deepseek-ai/deepseek-harness)
