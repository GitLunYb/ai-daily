## Benchmark

### EVOMAL：自我进化编码 Agent 中的自投毒漏洞
**评分 7.3** | 08-26 | [链接](https://arxiv.org/abs/2608.25776v1)

DeepSeek 团队（8 位作者）识别出自我进化 LLM 编码 Agent 的一个漏洞：在从共享技能库检索技能进行模仿时，检索到的恶意技能可能导致 Agent 在编写自身工具时被"投毒"。这是 Agent 安全领域的重要发现，揭示了自我进化机制中的潜在攻击面。

### JIT-Agent：通过即时 Harness 进化扩展智能
**评分 7.3** | 08-26 | [链接](https://arxiv.org/abs/2608.25593v1)

16 位作者的研究表明，Agent 能力不仅由模型决定，Harness（内存管理、规划策略、行动协议、工具/技能编排）可能主导贡献。JIT-Agent 提出即时 Harness 进化方法，为 Agent 性能提升提供了新思路。
