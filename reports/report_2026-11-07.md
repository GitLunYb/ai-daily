- **Claude Code sends your email address to websites** ｜评分 9.9 ｜2026-11-05
  GitHub issue 披露：Claude Code 联网检索时写入形如 `my-session-slug/1` 的 `User-Agent` 请求头，其中可含用户邮箱地址。HN 1559 分、496 条评论，是本周讨论度最高的隐私事件。[链接](https://github.com/anthropics/claude-code/issues/107757)
  > **深入**：问题本质是"会话标识符即身份标识符"——把可关联到具体账号的 slug 放进对外请求头，等于给每个被访问站点一个稳定的用户指纹。对以"企业可控"为卖点的编码 agent 而言，这类默认行为会直接冲击采购决策；修复方式（哈希化/随机化 session slug）不难，难的是默认值的选择逻辑。
